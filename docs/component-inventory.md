## Supporting files

[BrandLink](../src/components/layout/brand-link.tsx) is the first new layout component, outside the 64-module UI directory. It composes NavigationLink with a decorative local Next Image and visible real name; its accessible name includes Home. The validated [brand record](../src/content/brand.ts) derives the name from site.name and fixes the destination to `/`. The 192px WebP derivative is 2,604 bytes, with [source/encoding provenance](../public/images/brand/brand-mark-source.json); originals remain unchanged. Browser specimens cover all three surfaces, target geometry, focus, reflow, failed images/fonts and preferences. L01-B mounts it in the root header; L03-A reuses it in the footer.

[src/styles/layout.css](../src/styles/layout.css) owns 4px spacing, responsive `layout-container`, radius roles, `touch-target` and inset landmark focus. [src/styles/motion.css](../src/styles/motion.css) owns explicit control/overlay transitions and reduced-motion protection. Existing shell sections consume the container; the skip link consumes touch sizing. These roles do not implement a React container or dialog.

[src/styles/typography.css](../src/styles/typography.css) owns the hierarchy and `type-display`, `type-control`, `type-control-strong`, `type-hint` and `text-measure` roles. They carry no interaction behavior or ARIA semantics.

Semantic surface/state values and focus protection live in [src/styles/colors.css](../src/styles/colors.css); globals.css provides the Tailwind role mappings and bounded dark variant. The registry's neutral preset remains in components.json; it does not override the active brand palette.
